### 📌 Featured Projects

#### 🏢 [REM Real Estate - Verified Property Platform](https://github.com/Riteshbw)
> *A high-performance cross-platform property discovery and partial investment platform engineered for builder developers and property seekers.*
- **Zero-Brokerage Disintermediation:** Eliminates middleman commissions by integrating native Android Intent Dialers and direct WhatsApp webhook routing.
- **Verified Authenticity:** Built-in pipelines for authenticated title deeds, land survey dimensions, and timestamped milestone photography.
- **Algorithmic Fractional Investment:** Mathematically partitions high-ticket land plots and commercial units into accessible micro-equity shares.
- **Tech Stack:** Kotlin, Android Jetpack, React.js, Tailwind CSS, Cloud SQL.
