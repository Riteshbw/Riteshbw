### 🚀 What I'm Building

#### **REM Real Estate — Cross-Platform PropertyListing App & Website**
*A production-ready platform featuring a native Android app and a responsive React web portal built for a real estate builder.*

**Technical Highlights & Engineering Complexities:**
- **Cross-Platform Architecture:** Built a dual-client ecosystem (native Kotlin app + React SPA) sharing a unified RESTful API to keep listings, media, and availability synchronized across desktop and mobile.
- **Multi-Category Asset Engine:** Engineered flexible data models to handle three completely different property types—land plots (survey boundaries, zoning), residential flats (BHK, amenities, floor plans), and commercial spaces.
- **Fractional Investment Framework:** Designed an equity-partitioning module that splits high-value properties into standardized micro-shares, featuring real-time quota validation, dynamic funding progress bars, and yield simulation models.
- **Verified Documentation Pipeline:** Structured the listing schema to mandate title deed records, survey numbers, and timestamped site photos to prevent duplicate or misleading postings.
- **Developer Admin Console:** Built an operational dashboard for the client to manage inventory lifecycles, monitor customer inquiries, and push construction milestone updates.
- **Status:** 100% working web prototype completed and tested locally; core catalog, multi-filter search, fractional investment, and admin workflows fully operational.
